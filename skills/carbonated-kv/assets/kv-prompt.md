# シュワシュワKV 実装プロンプト（完全版）

> 炭酸飲料ブランド風の全画面キーヴィジュアルを、単一の自己完結HTMLとして実装するためのプロンプト。
> ブランドに合わせて差し替えるのは主に「コピー／カラー／書体」の3点。それ以外の数値は
> チューニング済みなので、まずはそのまま実装し、フレーム検証の結果を見てから微調整する。
>
> 出典：note記事「KVだけまず作るのが簡単で導入しやすい！シュワシュワサイトのプロンプト入れます！」
> （楠本 愛）。以下をそのまま実装指示として使用する。

# 役割
あなたは20年のキャリアを持つプロフェッショナルのWebデザイナー／グラフィックデザイナーです。
実装力もあり、WebGL・シェーダー・Canvas APIを使ったインタラクティブなKV制作を得意としています。
「なんとなく動く」ものではなく、実務で納品できる品質を出してください。

# 目的
飲料ブランド風の全画面キーヴィジュアル（ファーストビューのみ）を、
単一の自己完結HTMLファイルとして実装してください。
巨大なタイポグラフィが「炭酸液体の向こう側」にあるように揺らいで見える表現です。

# 技術構成（この3層構造を必ず守る）

1. **静的テクスチャ層** — 背景色と文字を 2D canvas に一度だけ描画し、WebGLテクスチャ化する
   （文字は毎フレーム描き直さない。リサイズ時のみ再生成）
2. **WebGL層** — フラグメントシェーダーでテクスチャのUVを歪める。液体の屈折のみを担当
3. **泡層** — 別の 2D canvas をオーバーレイし、白い円で炭酸の泡を描く
4. ヘッダー・サイドラベルは通常のDOM（キャンバスに描かない）

**重要**：泡をフラグメントシェーダー内でループさせないこと。全ピクセル×泡の数の計算になり破綻します。

# デザイン仕様

## カラー
- 背景：#DED4F7（淡いパープル）
- メイン文字：#C7FF1A（蛍光黄緑）
- ゴースト文字：#D6CCF4（背景よりわずかに濃い）
- 小さい文字（ヘッダー・ラベル）：#3B2870（濃いパープル）

## タイポグラフィ
- コピー：KUMO FLASH（1行）
- 書体：Google Fonts の **Anton**
- **横方向に0.48倍の長体をかける**（ctx.scale(0.48, 1)）
  → 極細コンデンス書体（Steelfish Extra Bold 系）の字面を再現するため。
  縮小によりステム比が本家に近づく
- letterSpacing：-0.005em
- 横幅：横長画面で画面幅の **75.5%**、縦長画面で **92%** に合わせてフォントサイズを逆算
- cap高さの上限：画面高の **55%**（超えたら縮小）
- 縦位置：cap中心を画面高の **54.5%**
- ゴースト：同じ文字を **1.06倍**、X を cx*1.008、ベースラインを cap*0.10 上にずらして背面に描く

## ヘッダー
- 高さ50px、蛍光黄緑の帯、文字は濃いパープル
- 左にロゴ（Anton・scaleX(.82)）、右にナビ2つ＋4本バーのイコライザーアイコン（CSSアニメーション）
- ナビ：13px / weight 600 / letter-spacing .10em

## サイドラベル
- 画面左右の端に縦組み（rotate(90deg)）
- 11px / weight 600 / letter-spacing .26em / 濃いパープル
- 上下2箇所ずつ、計4本

# シェーダー仕様（数値をそのまま使う）

UVは vUv.y = 0 が画面上端。precision mediump float。

## 水面の定義

```glsl
float surface(float x, float t){
  return 0.325
       - 0.190*x
       + 0.018*sin(x*4.6 + t*0.55)
       + 0.010*sin(x*9.3 - t*0.83)
       + 0.012*sin(t*0.37);
}
```

右上がりに傾いた水面が、2つの正弦波でゆっくり揺れる。
**この位置が文字の上1/3を横切ることが重要**（歪みは水面際で最も強く出るため）。

## 歪み（この順に適用）

```glsl
float d   = uv.y - surface(uv.x, t);   // >0 が液体の中
float dl  = max(d, 0.0);
float inL = smoothstep(0.0, 0.03, d);
vec2  w   = uv;

// 1. メニスカス圧縮（水面際で文字が吸い寄せられて潰れる）
w.y = s + dl*(1.0 - 0.13*exp(-dl*70.0)) + min(d, 0.0);

// 2. 水面をまたぐ横ずれ
float above = 1.0 - smoothstep(-0.030, 0.012, d);
w.x += above * (0.009 + 0.004*sin(t*0.6));

// 3. 液体内のうねり
w.x += inL * (0.0032*sin(uv.y*9.0  + t*0.85)
            + 0.0016*sin(uv.y*19.0 - t*1.35)
            + 0.0065*sin(uv.x*2.1  + t*0.45));
w.y += inL * (0.0026*sin(uv.x*7.5  + t*0.70));

// 4. ガラス越しのわずかな屈折
w = mix(w, (w-0.5)*0.990 + 0.5, inL);

// 5. ポインタ追従の波紋
vec2  dm = (uv - uMouse) * vec2(uAspect, 1.0);
float rm = length(dm) + 1e-4;
w += (dm/rm) * exp(-rm*7.0) * 0.016 * sin(rm*26.0 - t*3.2) * uMouseAmt;

// 6. 水面のハイライト
col = mix(col, vec3(1.0), exp(-abs(d)*420.0)*0.08);
```

サンプリングは clamp(w, 0.0, 1.0)、テクスチャは CLAMP_TO_EDGE。

# 泡の仕様（2D canvasオーバーレイ）

- 個数：**420個**
- サイズ配分（画面高に対する半径）
  - 70%：0.0014 〜 0.0038（極小。シュワシュワ感の主役）
  - 25%：0.0032 〜 0.0070
  - 5%：0.0070 〜 0.0130
- 上昇速度：(0.055 + 0.16*rand)、半径0.0032未満はさらに **1.35倍**（小さい泡ほど速い）
- 経路：画面下 y=1.06 → 水面 surface(x,t)+0.010 で消える
- 横揺れ：x + 0.010*sin(t*1.6 + 位相)
- 出入りのフェード：進行率0〜0.06で出現、0.88〜1.0で消滅
- **アルファを5段階に量子化してパスをまとめ、fill() は1フレーム5回だけ**にする
  （420回 fill() を呼ばない）
- 水面の関数はシェーダーとJS側で同じものを使い、泡が水面で消えるようにする

# パフォーマンス要件（必須）

- getContext('webgl', {antialias:false, alpha:false, depth:false, stencil:false, powerPreference:'high-performance'})
- devicePixelRatio の上限を **1.5**、さらに実効ピクセル数の上限を **220万px** にクランプ
- テクスチャの横幅上限 2048px
- 起動から60フレーム計測し、平均フレーム時間が22msを超えたら一度だけ解像度を0.7倍にして再構築
- visibilitychange で非表示時は requestAnimationFrame を停止
- resize は150msデバウンス
- prefers-reduced-motion: reduce で動きを止める

# 制約

- 外部ライブラリ（three.js等）は使わない。素のWebGL APIで書く
- 1ファイル完結（読み込むのはGoogle Fontsのみ）
- 日本語のコメントを要所に入れる
- KVのみ。下層セクションは作らない

# 検証手順（必ず実施）

実装後、ヘッドレスChromeで**時間をずらした2〜3フレーム**をスクリーンショットして確認してください。
液体アニメーションは時間によって見え方が大きく変わるため、1枚だけでは判断できません。

```bash
chrome --headless=new --hide-scrollbars --enable-unsafe-swiftshader \
  --window-size=1600,820 --virtual-time-budget=7000 \
  --screenshot=kv.png "http://localhost:PORT/"
```

以下を目視で確認し、崩れていれば数値を調整してください。

- 文字が読めるか（歪ませすぎて溶けていないか）
- ゴーストがメイン文字と喧嘩していないか
- 文字の上端がヘッダーに隠れていないか、下端が画面外に出ていないか
- 水面のラインが文字の上1/3を横切っているか
- 泡が十分な密度で見えるか
