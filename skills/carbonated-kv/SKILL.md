# Carbonated KV (シュワシュワKV)

炭酸飲料ブランドのファーストビュー（KVのみ）を、単一の自己完結HTMLで作るためのスキル。
巨大なタイポグラフィが「炭酸液体の向こう側」で屈折して揺らぎ、無数の泡が立ち上る表現を、
外部ライブラリなし（素のWebGL API）で実装する。

出典：note記事「KVだけまず作るのが簡単で導入しやすい！シュワシュワサイトのプロンプト入れます！」
（楠本 愛 / 17年目WEBデザイナー）を元にスキル化。

## このスキルが作るもの

- 全画面のKV（ファーストビューのみ。下層セクションは作らない）
- 蛍光色の巨大タイポ＋背面のゴースト文字
- WebGLフラグメントシェーダーによる液体の屈折・水面のうねり
- 2D canvasオーバーレイで描く炭酸の泡（数百個）
- ポインタ追従の波紋、reduced-motion対応、パフォーマンスガード

## 進め方

### 1. 再現レベルを決める（最初に100点を狙わない）

参考の飲料ブランドサイトがある場合は、まず技術構成をざっくり把握してから、以下から選ぶ：

- **A：見た目クローン** — KVの見た目だけを再現（最も簡単・導入しやすい。まずここから）
- **B：本気の3D** — WebGL/シェーダーで挙動まで作り込む
- **C：デザイン転用** — 配色・タイポの考え方だけ自分のブランドに転用

迷ったら **A** から。このスキルの標準プロンプトは A〜B 相当のKVを一発で出す。

### 2. プロンプトに沿って実装する

`assets/kv-prompt.md` に、役割・技術構成・デザイン仕様・シェーダー仕様・泡仕様・
パフォーマンス要件・検証手順まで含む完全なプロンプトが入っている。**これを実装指示として
そのまま使う**。ユーザーのブランドに合わせて差し替えるのは主に次の3点：

- **コピー（KV文字列）**：既定は `KUMO FLASH`
- **カラー**：背景／メイン文字／ゴースト／小文字の4色
- **書体**：既定は Google Fonts の Anton（長体をかけて極細コンデンスの字面を再現）

それ以外のシェーダー係数・泡パラメータは**チューニング済みなので原則そのまま使う**
（下記「守るべき原則」参照）。

### 3. 生成後は必ずフレーム検証する

液体アニメは時間で見え方が大きく変わるため、静止画1枚では判断できない。
ヘッドレスChromeで**時間をずらした2〜3フレーム**を撮って目視確認する。

```bash
chrome --headless=new --hide-scrollbars --enable-unsafe-swiftshader \
  --window-size=1600,820 --virtual-time-budget=7000 \
  --screenshot=kv.png "http://localhost:PORT/"
```

チェック項目：文字が読めるか（溶けていないか）／ゴーストが主文字と喧嘩していないか／
文字上端がヘッダーに隠れていないか・下端が画面外に出ていないか／
水面ラインが文字の上1/3を横切っているか／泡が十分な密度で見えるか。
崩れていれば数値を微調整して再生成する。

## 守るべき原則（これを外すと破綻する）

1. **3層構造を必ず守る**
   - 静的テクスチャ層：背景色と文字を2D canvasに**一度だけ**描いてWebGLテクスチャ化（毎フレーム描き直さない／リサイズ時のみ再生成）
   - WebGL層：フラグメントシェーダーでテクスチャUVを歪める（液体の屈折のみ担当）
   - 泡層：別の2D canvasをオーバーレイして白い円で泡を描く
   - ヘッダー・サイドラベルは通常のDOM（キャンバスに描かない）
2. **泡をフラグメントシェーダー内でループさせない** — 全ピクセル×泡数の計算になり破綻する。泡は必ず2D canvas側で描く。
3. **泡の fill() は1フレーム最大5回** — アルファを5段階に量子化してパスをまとめる（数百回 fill() を呼ばない）。
4. **シェーダーのsin波係数・exp値・泡パラメータはチューニング済み** — むやみに変えない。まず既定値で出し、検証結果を見てから微調整する。
5. **水面の関数はシェーダーとJSで同一** — 泡が水面でちゃんと消えるようにするため。

詳細な数値・シェーダーコード・泡配分・パフォーマンスのクランプ値は
`assets/kv-prompt.md` にすべて含まれている。実装時はそのプロンプトを開いて従うこと。
