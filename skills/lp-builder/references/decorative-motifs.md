# 装飾モチーフ活用ガイド

LP／KVで使う代表的な装飾モチーフの「呼び方・メリット・活用シーン・避けたい場面・実装ヒント」。
装飾は**主役（見出し・CTA・数値）を邪魔しない範囲で1〜2種に絞る**のが原則。盛りすぎると量産感・
安っぽさが出る。ブランドのトーン（信頼／親しみ／高揚／先進）に合うものを選ぶ。

---

## 1. バルーンテキスト（Balloon / Inflated typography）

- **英語**：balloon text / inflated (puffy) typography / gummy 3D lettering
- **メリット**：膨らんだ立体感で一瞬で目を引き、柔らかく親しみやすい印象を与える。1語でも“主役”を作れるので、短いキャッチやブランド名の訴求力が跳ね上がる。手触り感（触れそう）で記憶に残る。
- **活用シーン**：Y2K/ポップ系ブランド、キャンペーン・セール、飲料・お菓子・エンタメ、若年層向け、イベント告知のメインビジュアル。
- **避けたい場面**：金融・医療・士業など堅実さ・信頼が最優先の場面（軽く見える）。本文や長文には不向き（可読性が落ちる）。
- **実装ヒント**：見出し1語に限定。多重の内側シャドウ＋ハイライト＋やわらかいドロップシャドウで“ぷっくり”を作る。素材（3DレンダPNG）を使うのが手早い。CSSなら `text-shadow` の重ねがけ＋グラデ塗り、または SVG に inner glow。

## 2. ウォータードロップ（Water drop / Droplet）

- **英語**：water drop / droplet（結露=condensation、朝露=dewdrop、液体全般=liquid/aqua）
- **メリット**：みずみずしさ・清涼感・鮮度・純度を直感的に伝える。透明感で高級感も出せる。光の反射で写真の情報量が上がり、質感がリッチに見える。
- **活用シーン**：飲料・ビール・ミネラルウォーター、化粧品・スキンケア（保湿・うるおい）、清涼・夏キャンペーン、クリーン系サービス。缶やボトルの結露は「冷えてておいしそう」を演出。
- **避けたい場面**：温かみ・乾いた質感を出したいブランド、和/オーガニックの素朴系。多用すると画面がベタつく印象に。
- **実装ヒント**：主要ビジュアルの上に散らす／ヒーロー端に添える。CSSは径の異なる半透明円＋内側ハイライト＋わずかなブラーで擬似的に。動かすなら Canvas でゆっくり落下・合体。背景に敷くより被写体（缶・肌）に乗せる方が効く。

## 3. ドゥードゥル（Doodle）

- **英語**：doodle / hand-drawn scribble / sketchy elements（星・矢印・波線・囲みなど）
- **メリット**：手描きの温かみ・親近感で、機械的・堅い印象を和らげる。要素を「囲む・指す・つなぐ」ことで視線誘導や強調に実用的に使える（装飾かつ機能）。低コストで“人間味”を足せる。
- **活用シーン**：教育・子ども向け、クリエイター・個人事業、カジュアルなSaaS/コミュニティ、採用・社風紹介、注釈や「ここ注目！」の強調。
- **避けたい場面**：ラグジュアリー／ハイテク／重厚な信頼訴求（安っぽく見える）。多用すると散らかって見える。
- **実装ヒント**：CTAや数値の周りに1〜2個だけ。矢印で次アクションへ誘導、丸囲みで数値を強調、と“意味のある位置”に置く。SVGパスでインライン化すると色替え・軽量化が容易。`stroke-dasharray` で手描きアニメも可。

## 4. 市松模様（Checkerboard / Checkered）

- **英語**：checkerboard / checkered pattern（伝統名 ichimatsu。gingham/plaid は別の格子）
- **メリット**：規則的な2色格子でリズムと安定感を出す。和モダン〜レトロ〜レーシング（旗）まで振れ幅が広い。背景やセクション区切りに敷くと“余白の間”を埋めつつうるさくなりにくい。伝統柄として「繁栄・途切れない」の縁起の意味も。
- **活用シーン**：和・和菓子・日本文化、レトロ/カフェ、スポーツ・モータース（チェッカーフラッグ）、フェス・イベント、フッターや帯の背景。
- **避けたい場面**：全面に高コントラストで敷くと目がチカチカする／モアレ。繊細・ミニマル系では過剰。
- **実装ヒント**：CSSの `conic-gradient` か `linear-gradient` の繰り返しで純CSS実装できる（画像不要・軽量）。低コントラスト配色（背景色＋わずかに濃い同系色）で“うっすら”敷くのが上品。帯・フッター・見出し背景に部分使い。

```css
.checker { background:
  conic-gradient(#00000010 90deg, #0000 90deg 180deg, #00000010 180deg 270deg, #0000 270deg);
  background-size: 28px 28px; }
```

## 5. ホログラム（Holographic / Iridescent）

- **英語**：holographic / iridescent / holo foil（chrome iridescent）
- **メリット**：見る角度で虹色に変化する質感で、近未来・先進・特別感を強く演出。プレミアム／限定／テック感を一発で出せる。グラデが情報量を足し、単調な面を華やかにする。
- **活用シーン**：Y2K/ストリート、コスメ・ネイル、テック/Web3/ガジェット、限定コラボ・NFT、音楽・ナイトイベント。
- **避けたい場面**：ナチュラル/オーガニック、堅実な法人・公共（浮ついて見える）。全面ギラつきは可読性・信頼性を下げる。テキスト背景に使うなら文字色コントラストに注意。
- **実装ヒント**：`conic-gradient`/`linear-gradient` で虹色を作り、`background-clip:text` で文字に、`mix-blend-mode` で箔っぽく。アクセント（バッジ・ボタン・区切り線）に限定。動かすなら hover でグラデ位置をずらす。

```css
.holo { background: linear-gradient(120deg,#ff8ad8,#8ab0ff,#8affd1,#fff29a,#ff8ad8);
  background-size: 300% 300%; -webkit-background-clip:text; color:transparent; }
```

## 6. コンフェッティ（Confetti）

- **英語**：confetti / paper scatter（紙吹雪）
- **メリット**：祝祭・達成・高揚感を瞬時に伝える。動きを付けると“おめでとう／やった”の感情演出になり、完了画面や成果訴求のフックに最適。彩り豊かで画面が華やぐ。
- **活用シーン**：キャンペーン・記念・周年、申込/購入完了（サンクスページ）、実績・受賞の訴求、イベント・パーティ、ゲーミフィケーション。
- **避けたい場面**：落ち着き・信頼が主のBtoB本編、常時降らせ続ける（うるさい／集中を削ぐ）。CTAの視認を妨げない。
- **実装ヒント**：**イベント発火型**（CTA押下・完了時に一度だけ弾ける）が上品で効果的。Canvasで小さな矩形を重力＋回転で落とす。常設なら密度を薄く・低速に。`prefers-reduced-motion` で必ず抑制。

## 7. モーションブラー（Motion blur）

- **英語**：motion blur / speed blur / directional blur（アニメ的な集中線は speed lines）
- **メリット**：静止画に「動き・スピード・勢い」を与える。躍動感やスピード感、ライブ感を演出でき、視線を進行方向へ流せる。“速い・アクティブ”というブランド価値を視覚化。
- **活用シーン**：スポーツ・モビリティ・配送/物流、スピードを売りにするサービス（「最短」「即日」）、音楽・ダンス、変化・成長の表現。
- **避けたい場面**：精密さ・安定・安心が価値の領域（ブレ＝不安定・不明瞭に映る）。文字にかけると可読性が落ちる。
- **実装ヒント**：被写体の背景や軌跡にだけ方向性ブラーを。CSSは `filter: blur()` を要素の複製に方向マスクで、または素材（速度線PNG）を重ねる。“最短翌日”などの訴求語の後ろに薄く流すと意味と合致。過度なブラーは避け、方向を1つに揃える。

---

## 選び方の早見（トーン別）

- **親しみ・ポップ**：バルーンテキスト／ドゥードゥル／コンフェッティ
- **清涼・みずみずしさ**：ウォータードロップ
- **先進・特別感**：ホログラム／モーションブラー
- **和・レトロ・リズム**：市松模様
- **祝祭・達成の瞬間**：コンフェッティ（イベント発火）

原則：装飾は主役を引き立てる脇役。**同時に全開にするのは最大2種まで**（例：ホログラム＝色の主張 と
コンフェッティ＝動きの主張 を同時に強くしない）。`prefers-reduced-motion` を尊重し、動く装飾は必ず抑制分岐を用意する。
