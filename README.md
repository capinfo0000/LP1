# CareShift LP（サンプル）

介護・看護のスポット採用支援サービスを題材にした、B2B向けランディングページのサンプル（テンプレート）です。
`https://caitech.co.jp/lp/cm-office-3/` の構成を参考に、独自のデザイン・コピーで作成しています。

## 構成

- `index.html` … LP本体（HTML/CSS/JS をすべて内包した1ファイル）
- `assets/img/` … 写真素材（Pexels のフリー素材）と `CREDITS.md`

## 閲覧方法

ブラウザで `index.html` を開くだけで表示できます。

## デザイン

- パレット: 温かみのある紙白地 × パイン・ティール（信頼）× コーラル（CTA）
- タイポ: 見出し Zen Kaku Gothic New / 本文 Noto Sans JP / 数値 Outfit
- レスポンシブ対応・`prefers-reduced-motion` 尊重・スクロールリビールあり

## 注意

サービス名・数値・社名・導入事例・料金はすべてダミーです。実サービスに合わせて差し替えてください。
